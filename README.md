# DebyeEliashberg

High-performance Fortran framework for solving isotropic Eliashberg superconductivity equations using Debye and spectral electron-phonon kernels.

## Overview

DebyeEliashberg is a scientific computing framework designed for large-scale numerical simulations of strongly coupled superconducting systems. The project focuses on self-consistent solutions of Eliashberg equations for electron-phonon mediated superconductivity.

The codebase emphasizes:

- High-performance numerical methods
- Self-consistent iterative solvers
- Scientific computing workflows
- Linux/HPC compatibility
- Modular Fortran architecture
- Spectral and Debye kernel implementations

## Features

- Isotropic Eliashberg solver
- Debye phonon kernel
- Spectral electron-phonon kernels
- Self-consistent gap calculations
- Numerical convergence control
- Modular Fortran source structure
- HPC-oriented workflows

## Technologies

- Fortran
- Linux
- Makefile build system
- HPC numerical workflows

## Repository Structure

```text
src/        Core numerical solvers
examples/   Example simulations
build/      Compiled object files
bin/        Executables
```

## Compilation

```bash
make
```

## Research Context

This project was developed as part of computational condensed matter and superconductivity research at the National Autonomous University of Mexico (UNAM).

Results obtained using this framework contributed to peer-reviewed scientific research and published work on Eliashberg superconductivity and hydride materials.
